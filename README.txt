TASK MANAGER SYSTEM USING PRIORITY QUEUE
============================================

Language: Python
Main DSA: Priority Queue
Implementation: Python heapq (min-heap)

Priority Levels:
1 = High
2 = Normal
3 = Low

Operations:
- enqueue() : Add a task
- dequeue() : Process the highest-priority task
- peek()    : View the next task without removing it
- display() : Display waiting tasks

For equal priorities, the order number preserves FIFO order.

How to Run:
1. Install Python 3.
2. Open Terminal/Command Prompt in this folder.
3. Run: python app.py

No external packages are required.
